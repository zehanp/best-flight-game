Langit Biru — a complete original flight game for the browser: fly through rings, land on the runway, manage fuel and weather.

## Run it

```sh
npx --yes serve .
# lalu buka http://localhost:3000/game/
```

## Cara bermain

Terbang melewati semua cincin emas, lalu mendarat di landasan. Panah mengarahkan pesawat, W/S mengatur throttle, P jeda, M bisu, C menyimpan screenshot. Bahan bakar berkurang saat terbang dan bertambah di setiap cincin; mendarat dengan kecepatan rendah dan sikap lurus untuk menyelesaikan kursus. Setiap kursus berikutnya lebih panjang dan berangin.
